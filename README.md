# 🗳️ C++ Voting System 📊

Welcome to the **Voting System** repository! This project is a secure, console-based C++ application designed to simulate an electronic voting process, enabling voters to cast ballots, candidates to be registered, and votes to be tallied accurately and transparently.

🌐 **Repository Link:** [https://github.com/FariaSajid/Voting-System](https://github.com/FariaSajid/Voting-System)

---

## ✨ Features

- **Candidate Management:** Register, view, and organize candidates running for election.
- **Secure Ballot Casting:** Allows voters to cast their votes securely with validation checks to prevent multiple voting.
- **Real-Time Vote Tallying:** Automatically calculates and updates vote counts for each candidate.
- **Election Results:** Displays a clear, itemized summary of election results and declares the winner.
- **Data Persistence:** Utilizes file handling to save voter logs and election results securely.

---

## 🛠️ Tech Stack & Concepts

- **Language:** C++
- **Key Concepts:**
  - Object-Oriented Programming (OOP) principles (Classes, Objects, Encapsulation)
  - Data Structures (Vectors, Arrays, Structs) for handling candidates and voter records
  - File I/O (`fstream`) for data storage and persistence
  - Control flow, loops, and robust input validation
